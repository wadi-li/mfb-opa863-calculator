Синусоида

Установившийся периодический режим: сумма гармоник входного сигнала через реальную передаточную функцию каскада, затем ограничение по размаху выхода. Задержка фильтра видна как сдвиг выхода относительно пунктира.

Расчётные соотношения

H(s) = −(R2/R1) / (1 + s·C2·(R2 + R3 + R2·R3/R1) + s²·R2·R3·C1·C2) f0 = 1 / (2π·√(R2·R3·C1·C2)) Q = √(R2·R3·C1·C2) / (C2·(R2 + R3 + R2·R3/R1)) Условие реализуемости: C1/C2 ≥ 4·Q²·(1 + R2/R1) DC: Vвых = (1 + G)·Vb − G·Vвх, G = R2/R1 → Vb = Vвых(0)/(1 + G) Бессель 2-го порядка: f0 = 1,2736·f−3дБ, Q = 0,5773; фазолинейный 0,05°: f0 = 1,2098·f−3дБ, Q = 0,5997 Реальная модель: A(s) = A0/(1 + s·A0/(2π·GBW)), Cвх на IN−, узловой анализ без упрощений.
