# Калькуляторы активных ФНЧ

## Онлайн-калькуляторы

- [MFB ФНЧ второго порядка на OPA863](https://wadi-li.github.io/mfb-opa863-calculator/)
- [Неинвертирующий ФНЧ первого порядка на TLV9061](https://wadi-li.github.io/mfb-opa863-calculator/tlv9061-lpf.html)

### TLV9061

Однополярное питание 3,3 В, начальный коэффициент усиления 1,2. Схема, подбор номиналов E24/E96, АЧХ, фаза, проверка диапазона и совмещённые осциллограммы входной синусоиды и ожидаемого выхода. Частота, амплитуда и смещение сигнала настраиваются. Ограничение выхода моделируется упрощённо.

При входе 3 В и Ку = 1,2 идеальный выход составляет 3,6 В, что превышает питание 3,3 В. Калькулятор показывает это ограничение.

### OPA863

Автономный HTML-калькулятор каскада MFB ФНЧ 2-го порядка (Бессель / фазолинейный 0,05° / свои f0, Q) на ОУ TI OPA863 с однополярным питанием 3,3 В.

- Подбор R из ряда E24 и C из ряда E6 с ранжированием по реальной АФЧХ (GBW, Aol, Cвх ОУ)
- Сдвиг уровня: Vвых = (1+G)·Vb − G·Vвх, расчёт делителя Vb
- Проверка диапазона входа/выхода, мощности R1, перегрузки, SR, петлевого усиления
- АЧХ, ФЧХ, групповая задержка, Монте-Карло по допускам
- Осциллограммы треугольника, меандра и синуса до и после фильтра
- BOM в CSV (`;`, UTF-8 с BOM), печать/PDF, светлая и тёмная темы

Оба калькулятора работают автономно: скачайте соответствующий HTML и откройте в браузере.
